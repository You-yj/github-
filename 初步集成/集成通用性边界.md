# FEALPy 集成通用性边界说明

> 回答一个问题：我们把双磁体算例集成进 fealpy 的部分，**到底通用到什么程度**？
> 本文所有结论均以 `初步集成/fealpy` 中代码的实际行为与测试为准。

## 1. 一句话结论

集成进 fealpy 的是「**命名区域网格 + 磁标势有限元 + Maxwell 应力算力**」这条求解/后处理管线。
它的通用性边界是：

> **任意共形四面体网格 + 分片常数线性各向同性材料 + 无自由电流的磁标势适用域**。

几何生成器 `BoxRegionMesher` 只支持轴对齐长方体，但模型通过
`RegionTaggedMeshDataProtocol` 与几何生成器**解耦**——几何形状的扩展只需
换一个满足协议的网格器，模型与后处理一行不用改。

## 2. 逐层"能 / 不能"表

| 层 | 通用（已验证或代码可确认） | 受限（当前版本） |
|---|---|---|
| 材料 `fealpy.material` | 任意磁化方向与大小（三维向量）；任意正 μᵣ；自定义材料类只需满足 `MagneticMaterialProtocol`；材料对象不可变 | 线性、各向同性、标量 μᵣ；M 分片常数（每区域一个值）；无非线性 B-H 曲线、无张量磁导率 |
| 网格 `fealpy.mesher.BoxRegionMesher` | **任意数量**轴对齐长方体；任意中心/尺寸/优先级；区域可重叠（priority 归属）；多个 Box 尺寸场（Min 组合）；命名界面任意多；角点形式逐位复现几何 | 仅轴对齐长方体；加密/重编号后单元标签不自动 remap（需调用方迁移） |
| 模型 `fealpy.cem.fem.MagnetostaticLFEMModel` | 任意 p≥1 连续 Lagrange 元；μᵣ 分片常数（=1 与非 1 均有测试）；函数型磁化源 `set_magnetization_source`；任意满足网格数据协议的网格；显式规范点处理纯 Neumann | 无用户指定 Dirichlet 边界；多连通域需预先引入 cut；求解走 SciPy/PyAMG（CPU 路径） |
| 后处理 `compute_force` | 任意命名闭合界面；法向由相邻单元质心拓扑确定（不依赖盒形状，可非凸）；材料界面两侧为空气时应力公式有效（有物理检查） | 积分面必须在 μᵣ=1、M=0 的空气中；函数型磁化源暂不支持算力 |
| 算例层（不进 fealpy） | 几何尺寸、磁体个数/位置、材料绑定、位移扫描、参考对标全部可自由改 | 本来就是 benchmark 专属，不属于通用组件 |

## 3. 直接回答常见问题

### Q1：磁体可以不是长方体吗？
**网格器当前不能直接生成**（`BoxRegionMesher` 只做轴对齐盒）；但**模型与后处理对几何形状没有任何假设**——换一个能出圆柱/球/旋转体/STEP 网格的网格器（提供 `mesh / cell_tags / region_tags / interface_names / tag` 五件套），求解与算力原样可用。几何扩展是"加一个网格器"，不是"改模型"。

### Q2：磁体的大小、位置、个数可以变吗？
可以。全部是配置层数据：
```python
"regions": [
    {"name": "magnet_a", "lower": [...], "upper": [...], "priority": 10},
    {"name": "magnet_b", "lower": [...], "upper": [...], "priority": 10},
    ...
]
```
加一块磁体 = regions 加一项 + 材料字典加同名绑定，共 4 行；位置/尺寸就是两个角点。

### Q3：可以加一个长方体吗？多个呢？
可以，任意多个，见 Q2。重叠区域由 priority 决定归属（这正是 Maxwell 盒包磁体的用法）。

### Q4：磁化方向可以不同吗？
可以。每个区域绑定独立的 `PermanentMagnet`：
```python
materials = {
    "magnet_a": PermanentMagnet([0.0, 0.0, MZ]),   # +z
    "magnet_b": PermanentMagnet([MZ, 0.0, 0.0]),   # +x
    ...
}
```

### Q5：可以有 μᵣ ≠ 1 的软磁材料吗？
可以。用 `LinearMagneticMaterial(relative_permeability=250.0)`；变系数组装路径有测试
（`test_assemble_nonunit_relative_permeability`、分块版另有 μᵣ=5 vs 1 矩阵对比测试）。

### Q6：可以同时算多个力吗？
可以。定义多个命名界面，逐个调用 `model.compute_force(name)`；每个界面的法向都按
拓扑独立定向。

### Q7：网格尺寸、加密策略可以变吗？
可以。`size_fields` 支持多个 Box 场（自动取 Min）；近细远粗只是 benchmark 的一种用法，
通用组件不限定"近场必须细于远场"。

## 4. 明确不通用（诚实边界）

1. **物理前提**：磁标势要求域内无自由电流（∇×H=0）；单值标势要求区域拓扑合适
   （多连通域需先引入 cut）。电流问题、时谐涡流问题不属于本组件。
2. **材料模型**：线性、各向同性、标量 μᵣ；非线性、各向异性、随场变化的本构不在内。
3. **边界条件**：只支持齐次自然 Neumann（磁绝缘截断）+ 内部规范点；用户指定的
   Dirichlet / 磁通边界尚未实现（文档已知限制）。
4. **几何生成**：非长方体形状需要新的网格器（模型侧无需改动）。
5. **网格演化**：加密/重编号后 attributes 不自动 remap，调用方需自行迁移标签。
6. **求解后端**：线性系统经 SciPy/PyAMG 在 CPU 求解；GPU 原生路径不在内。

## 5. 通用性的关键设计（为什么能这样分层）

| 设计 | 作用 |
|---|---|
| `MagneticMaterialProtocol` | 材料可替换——任何满足协议的对象都能用，不锁死内置三类 |
| `RegionTaggedMeshDataProtocol` | 网格可替换——模型不绑定 BoxRegionMesher，几何扩展=换网格器 |
| 命名区域（name → tag） | 模型与后处理只见名字，不见整数——新算例不需要 `cell_tag >= 2` 这类硬编码 |
| 拓扑法向定向 | 不依赖 Maxwell 盒中心，非凸积分面同样正确 |
| 物理条件检查 | Maxwell 面两侧必须 μᵣ=1、M=0，杜绝在材料界面误用真空应力公式 |
| 逐单元标签存 mesh attribute | 标签随网格走（VTU 导出、其他工具可读），mesher 只是"生产"标签 |

## 6. 新算例的四步流程（任意数量长方体磁体）

```python
# 1) 几何（任意多区域）
mesher = BoxRegionMesher(options={... "regions": [磁体1, 磁体2, ...]})
mesher.init_mesh()

# 2) 材料（逐区域绑定，方向/大小/μᵣ 任意）
model = MagnetostaticLFEMModel(p=2, mu0=MU0)
model.set_mesh_data(mesher)
model.set_materials({"air": Air(), "magnet_1": PermanentMagnet([0,0,M1]), ...})

# 3) 求解
model.solve()

# 4) 算力（可为每个 Maxwell 界面各算一次）
force = model.compute_force("maxwell_surface_1")
```

## 7. 一句话总结（讨论用口径）

> 通用的是**管线**（协议化模型 + Maxwell 应力 + 命名区域寻址），不是某一个几何形状。
> 轴对齐盒只是当前网格器的能力范围；换成任何满足网格数据协议的网格器，整条管线
> 原样复用——这是"值得进 fealpy"的论据，也是与老师讨论时的核心主张。

## 8. 实测证据：三磁体 + 软磁材料案例

用集成组件实测了一个**非双磁体**问题（脚本 `generic_magnet_case.py`）：

- magnet_a / magnet_b：20×10×10 mm，沿 +z 磁化，关于 x=0 镜像对称；
- magnet_c：10×10×20 mm，沿 +z 磁化（对称面上）；
- magnet_d：10×10×10 mm，沿 **+y** 磁化（不同方向）；
- soft_block：10×10×10 mm，**μᵣ=250** 软磁材料；
- 四个独立 Maxwell 盒分别包围 a/b/c/d，外加一个大盒包住全部物体（嵌套空气盒，priority=-1/0/10）。

**运行结果**（p=1，网格 19,903 节点 / 118,941 单元，CG 24 次收敛）：

| 对象 | 受力 (N) | 说明 |
|---|---|---|
| 组合体整体 F_all | (+0.004, −0.057, +0.012) | ≈ 0：孤立组合体自作用力为零 ✓ |
| magnet_a F_a | (−0.101, −0.006, −0.004) | 并排同向磁化相斥，被推向 −x ✓ |
| magnet_b F_b | (+0.094, +0.011, +0.001) | 镜像对象，被推向 +x，符号镜像 ✓ |
| magnet_c F_c | (−0.000, −0.004, −0.126) | 被下方组合体吸引（−z） |
| magnet_d(+y) F_d | (−0.002, −0.033, +0.136) | 不同磁化方向，受力非零 ✓ |

**四项校验全部通过**：① 所有力有限；② 组合体自作用力 ≈ 0（硬物理校验）；
③ a/b 镜像关系成立（符号镜像，量级在离散误差内一致）；④ μᵣ=250 变系数路径
端到端跑通。

**过程中的两个工程发现**（也是通用性使用要点）：

1. **嵌套 Maxwell 盒的界面命名**：内层盒的外侧相邻区域是外层盒（不是最外层空气），
   命名界面必须写 `("box_a_air", "box_all_air")`；外盒用更低 priority 先写、内盒
   后写覆盖、磁体最后覆盖。
2. **HXT 网格不保持镜像对称**：19,903 个节点中 17,515 个无镜像伙伴，因此镜像
   校验只能到离散误差水平（实测力差 ~7%）。对"对称性"类验证，要么用结构化网格，
   要么把容差放到离散误差水平。
