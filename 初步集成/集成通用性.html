Stage 03磁标势组件通用性说明

回答一个问题：集成进 fealpy 的组件到底通用到什么程度。 结论：通用的是「命名区域网格 + 磁标势有限元 + Maxwell 应力算力」这条管线， 而不是某一个几何形状——几何生成器可换，模型与后处理不动。 完整上下文见 集成详细版。

§1一句话结论

通用边界 = 任意共形四面体网格 + 分片常数线性各向同性材料 + 无自由电流的磁标势适用域
  • 材料层：任意磁化方向与大小、任意正 μᵣ、自定义材料类（协议即可）——完全通用；
  • 模型层：任意 p≥1、μᵣ 分片常数、函数型磁化源、任意满足网格数据协议的网格；
  • 后处理层：任意命名闭合空气界面，法向拓扑定向，可非凸；
  • 网格层：当前只支持轴对齐长方体——但这是"换网格器"的扩展点，不是断点。
关键分界：通用的是管线（协议化模型 + Maxwell 应力 + 命名区域寻址），不是某一个几何形状。轴对齐盒只是 BoxRegionMesher 的能力范围；换成任何满足 RegionTaggedMeshDataProtocol 的网格器，整条管线原样复用。
诚实边界：无自由电流（∇×H=0）、单值标势（多连通需 cut）、线性各向同性标量 μᵣ、只有齐次自然 Neumann + 内部规范点、非盒几何需新网格器、加密后标签不自动 remap。

§3能 / 不能边界表

层通用（已验证或代码可确认）受限（当前版本）
材料 fealpy.material任意磁化方向与大小；任意正 μᵣ；自定义材料类只需满足协议；对象不可变线性、各向同性、标量 μᵣ；M 分片常数；无非线性 B-H、无张量磁导率
网格 fealpy.mesher.BoxRegionMesher任意数量轴对齐长方体；任意中心/尺寸/优先级；重叠（priority 归属）；多个尺寸场；命名界面任意多；角点形式逐位复现几何仅轴对齐长方体；加密/重编号后标签不自动 remap
模型 fealpy.cem.fem.MagnetostaticLFEMModel任意 p≥1；μᵣ 分片常数（=1 与非 1 均有测试）；函数型磁化源；任意满足协议的网格；显式规范点无用户 Dirichlet；多连通需 cut；SciPy/PyAMG CPU 路径

算例层（不进 fealpy）几何尺寸、磁体个数/位置、材料绑定、扫描、对标全部可自由改本就是 benchmark 专属，不属于通用组件

§4常见问题

Q1：磁体可以不是长方体吗？
网格器当前不能直接生成（只做轴对齐盒）；但模型与后处理对几何形状没有任何假设——换一个能出圆柱/球/旋转体/STEP 网格的网格器（提供 mesh / cell_tags / region_tags / interface_names / tag 五件套），求解与算力原样可用。几何扩展是「加一个网格器」，不是「改模型」。
Q2：磁体的大小、位置、个数可以变吗？
可以。全部是配置层数据——改两个角点即改尺寸/位置；加一块磁体 = regions 加一项 + 材料字典加同名绑定，共 4 行。
Q3：可以加一个长方体吗？多个呢？
可以，任意多个。重叠区域由 priority 决定归属（这正是 Maxwell 盒包磁体的用法）。
Q4：磁化方向可以不同吗？
可以。每个区域绑定独立的 PermanentMagnet，任意三维向量（实测案例中 d 就是 +y）。
Q5：可以有 μᵣ ≠ 1 的软磁材料吗？
可以。LinearMagneticMaterial(relative_permeability=250.0)；变系数组装路径有单元测试，实测案例端到端跑通。
Q6：可以同时算多个力吗？
可以。定义多个命名界面，逐个 model.compute_force(name)；每个界面法向独立拓扑定向（实测案例一次算了 5 个力）。
Q7：网格尺寸、加密策略可以变吗？
可以。size_fields 支持多个 Box 场（自动取 Min）；「近场细于远场」只是 benchmark 的用法，通用组件不限定。

§5实测案例（generic_magnet_case.py）

用集成组件求解一个非双磁体问题：四块磁体（三种尺寸、+z/+y 两种方向）+ 一块 μᵣ=250 软磁 + 五个嵌套 Maxwell 盒（几何见 §2）。

对象受力 (N)说明
组合体整体 F_all(+0.004, −0.057, +0.012)≈ 0：孤立组合体自作用力为零 ✓
magnet_a F_a(−0.101, −0.006, −0.004)并排同向磁化相斥，推向 −x ✓
magnet_b F_b(+0.094, +0.011, +0.001)镜像对象，推向 +x，符号镜像 ✓
magnet_c F_c(−0.000, −0.004, −0.126)被下方组合体吸引（−z）
magnet_d(+y) F_d(−0.002, −0.033, +0.136)不同磁化方向，受力非零 ✓
四项校验全部通过：① 所有力有限；② 组合体自作用力 ≈ 0（硬物理校验，|F_all|max = 5.7e-2 N）；③ a/b 镜像关系成立（符号镜像，量级在离散误差内一致）；④ μᵣ=250 变系数路径端到端跑通。p=1，19,903 节点 / 118,941 单元，CG 24 次收敛。

5.1 两个工程发现

  • 嵌套 Maxwell 盒的界面命名：内层盒的外侧相邻区域是外层盒（不是最外层空气）——命名界面必须写 ("box_a_air", "box_all_air")；外层盒用更低 priority 先写、内层后写覆盖、磁体最后覆盖；
  • HXT 网格不保持镜像对称：19,903 个节点中 17,515 个无镜像伙伴——对称性类校验只能到离散误差水平（实测力差 ~7%），要么用结构化网格，要么放宽容差。
通用性结论：换一套几何与材料，四步流程原样复用、物理校验成立——「通用的是管线，不是某一个几何形状」有了实测证据。

§6通用性的设计根子

设计作用
MagneticMaterialProtocol材料可替换——任何满足协议的对象都能用，不锁死内置三类
RegionTaggedMeshDataProtocol网格可替换——模型不绑定 BoxRegionMesher，几何扩展 = 换网格器
命名区域（name → tag）模型与后处理只见名字，不见整数——新算例不需要 cell_tag >= 2 这类硬编码
拓扑法向定向不依赖 Maxwell 盒中心，非凸积分面同样正确
物理条件检查Maxwell 面两侧必须 μᵣ=1、M=0，杜绝在材料界面误用真空应力公式
逐单元标签存 mesh attribute标签随网格走（VTU 导出、其他工具可读），mesher 只是「生产」标签

附录新算例四步流程

# 1) 几何（任意多区域，角点形式）
mesher = BoxRegionMesher(options={"outer": ..., "regions": [磁体1, 磁体2, ...]})
mesher.init_mesh()

# 2) 材料（逐区域绑定，方向/大小/μᵣ 任意）
model = MagnetostaticLFEMModel(p=2, mu0=MU0)
model.set_mesh_data(mesher)
model.set_materials({"air": Air(), "magnet_1": PermanentMagnet([0,0,M1]), ...})

# 3) 求解
model.solve()

# 4) 算力（可为每个 Maxwell 界面各算一次）
force = model.compute_force("maxwell_surface_1")
