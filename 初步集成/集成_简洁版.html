03议题一落地：工程型定位

待确认的问题：制造解要不要注册为 fealpy.model.poisson 的 exp？答案是——不注册，退回测试本地。

主输入不兼容制造解的主输入是向量磁化场 M，边界条件是 B·n=0，通用 PoissonLFEMModel 的标量 source 与 Dirichlet 接口消费不了。
避免名义可发现放进 DATA_TABLE 会形成「名义可发现、实际不可互换」的公共算例——看起来是标准 exp，实际换不到别的模型上。
并非每个模型都要 expFEALPy 中并非每个领域模型都必须配一个 Exp；制造解留在模型测试内，继续承担收敛性验证职责。
保留的验证能力：Ω=(0,1)³ 真解 φ=sin(πx)sin(πy)sin(πz)，M=∇φ+∇×ψ（ψ 紧支撑 → B·n=0 精确成立），H¹ 误差随网格加密单调下降；网格用确定性的 TetrahedronMesh.from_box()，不依赖 Gmsh。

04议题二落地：归口 cem/fem

领域接口公共接口含 μ₀、μᵣ、M/H/B、永磁体与 Maxwell 应力——属于计算电磁学领域模型，复用 fealpy.fem 的通用形式与积分器。
依赖方向单向fealpy.cem.fem → fealpy.fem，通用 FEM 层不反向导入 CEM，无循环依赖。
与仓库先例对齐与 fealpy/csm/fem/ 的领域包组织一致，且 fealpy/cem/fem/ 子包早已预留——我们是它的第一个住户。
落地形态：模型从 fealpy.cem.fem 顶层导出 MagnetostaticLFEMModel / MU0 / SolverOptions / SurfaceData / RegionTaggedMeshDataProtocol / compute_maxwell_force。

05协议化接口与求解加固

材料协议MagneticMaterialProtocol（μᵣ、M 两个只读属性）——任何满足协议的对象都能当材料，不只三个内置类。
网格数据协议RegionTaggedMeshDataProtocol（mesh/cell_tags/region_tags/interface_names/tag）——模型不再绑定 BoxRegionMesher，圆柱、STEP、外部导入网格都能接入。
显式规范点纯 Neumann 常数核在 SciPy 副本上固定第 0 个自由度消除——只改变磁标势常数，不改变 H、B 与力（实测与奇异 CG 路径差异 ≤1.3e-10 N）。
函数式力入口compute_maxwell_force(mesh_data, materials, space, potential, surface)——流水线不必持有模型实例也能算力。
物理条件检查Maxwell 面两侧必须是 μᵣ=1、M=0——否则直接报错，杜绝在材料界面误用真空应力公式。
严格输入校验标签唯一性、材料协议、有限值、形状一致性全部在 set_* 时拦截，错误在求解前暴露。

07三版实现对比：求解流水线

结构持续演进，数值逻辑逐句对应——最初程序全在一个类方法里，分块拆成独立模块，集成换成 fealpy 公共接口。

① 最初程序 · solve(d)L388–408
self.d = float(d)
self.build_gmsh_mesh()      # 几何+网格+空间+Maxwell 面

stiffness, rhs = self.assemble()
phi = self._solve_linear_system(stiffness, rhs)
F0 = self.compute_maxwell_force(phi)
return {"d": self.d, "phi": phi,
        "F0": F0, "F1": -F0}
② 工程化分块 · solve()L106–129
geometry = make_geometry(displacement_mm)
mesh_data = GmshTetraMesher().generate(
    geometry, make_mesh_options(...))
solution = ScalarPotentialSolver(p=p).solve(
    mesh_data, make_pde())
lower_force = \
    MaxwellStressPostprocessor().compute_force(
        solution,
        "lower_magnet_maxwell_surface")
return {"d": ..., "solution": solution,
        "phi": solution.potential,
        "F0": lower_force, "F1": -lower_force}
③ FEALPy 集成 · solve()L120–140
mesher = make_mesher(displacement_mm,
                     h_near_mm, h_far_mm, show)
mesher.init_mesh(model_name=f"double_magnet_d{...}")
model = MagnetostaticLFEMModel(p=p, mu0=MU0)
model.set_mesh_data(mesher)
model.set_materials(make_materials())
model.solve()

return {"d": ..., "solution": model,
        "phi": model.uh,
        "F0": lower_force, "F1": -lower_force}
