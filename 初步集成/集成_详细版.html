§2两个议题的落地

2.1 议题一：工程型定位 制造解退回测试本地

  • 待确认的问题：制造解要不要注册为 fealpy.model.poisson 的 exp（DATA_TABLE=14）？
  • 决策：不注册。主输入是向量磁化场 M、边界条件是 B·n=0，通用 PoissonLFEMModel 的标量 source 与 Dirichlet 接口消费不了；放入 DATA_TABLE 会形成「名义可发现、实际不可互换」的公共算例；FEALPy 中并非每个领域模型都必须配一个 Exp。
  • 保留的验证能力：解析函数留在模型测试内——Ω=(0,1)³ 真解 φ=sin(πx)sin(πy)sin(πz)，M=∇φ+∇×ψ（ψ 紧支撑 → 边界 B·n=0 精确成立），H¹ 误差随加密单调下降；网格用确定性的 TetrahedronMesh.from_box()，不依赖 Gmsh。

2.2 议题二：归口 cem/fem fealpy/cem/fem/

  • 待确认的问题：磁标势模型留在 fealpy/fem/ 还是迁 fealpy/cem/fem/？
  • 决策：迁 cem/fem/。三条依据：① 公共接口含 μ₀、μᵣ、M/H/B、永磁体与 Maxwell 应力，属于计算电磁学领域模型（复用 fealpy.fem 的通用形式与积分器）；② 依赖方向保持 fealpy.cem.fem → fealpy.fem 单向，通用 FEM 层不反向导入 CEM，无循环依赖；③ 与 fealpy/csm/fem/ 的领域包组织一致，且 fealpy/cem/fem/ 子包早已预留。

§3协议化接口与求解加固

3.1 材料协议 fealpy/material/magnetic_material.py

  • MagneticMaterialProtocol：两个只读属性（μᵣ、M）——任何满足协议的对象都能当材料，不只三个内置类；
  • Air：μᵣ=1、M=(0,0,0)；
  • LinearMagneticMaterial：任意正 μᵣ 的线性各向同性材料；
  • PermanentMagnet：B = μ₀(μᵣH+M) 形式，磁化强度以不可变 tuple 存储（frozen 数据类不被 ndarray 原地修改）。

3.2 网格数据协议 RegionTaggedMeshDataProtocol

  • 模型只要求 mesh / cell_tags / region_tags / interface_names / tag 五个成员，不再绑定 BoxRegionMesher；
  • 任何共形四面体网格提供者（圆柱、STEP、外部导入）都能接入；
  • set_mesh_data 严格校验：三维四面体、标签整数 dtype、标签值 ⊆ region_tags、名称唯一、界面引用存在——错误在求解前暴露。
标签存放与网格侧机制对齐：逐单元标签存为 mesh cell sector 的 "region" attribute（新网格机制正统），BoxRegionMesher.cell_tags 读透该 attribute——写 VTU 时自动成为 cell data；region_tags（name→int）与 interface_names 属几何语义元数据，留在 mesher 上。已知限制：网格加密/重编号后 attributes 不自动 remap（本算例每工况重建网格，不受影响）。

3.3 显式规范点 solve() · gauge pinning

  • 纯 Neumann 刚度矩阵有常数核；在 SciPy 副本上把第 0 个自由度整行整列清零、对角置 1、右端置 0——系统变为非奇异；
  • 该操作只改变磁标势的任意常数，不改变 H、B 与力（同网格实测与奇异 CG 路径差异 ≤ 1.3e-10 N）；
  • 通过 callback 记录真实 CG 迭代数，存入 solver_info（cg_info / cg_iterations / gauge_dof）。

3.4 函数式力入口 compute_maxwell_force()

  • 模块级函数：网格数据 + 材料 + 空间 + 势 + 界面名 → 力 (3,)，后处理流水线不必持有模型实例；
  • 校验 space 的 Lagrange 次数、space 与 mesh 的同一性、势的形状；
  • 复用模型的 compute_force()，公式只有一份。

5.2 角点形式为什么关键

四个区域全部用角点形式（代码见 §4.1 第 ③ 栏）：center/size 往返会差 1 ulp，足以改变 Gmsh 网格（实测力差约 2e-6 N）；角点形式把最初程序的角点算式原样传给 Gmsh → 网格逐位一致。带参数名的快速失败（d≥0、h_near≤h_far）是算例语义，刻意留在 benchmark 层而非 fealpy。

§6通用性实测：三磁体 + 软磁案例

通用性不是嘴上说的——用集成组件实测一个非双磁体问题（脚本 generic_magnet_case.py）：四块磁体（三种尺寸、两种磁化方向）+ 一块 μᵣ=250 软磁材料 + 五个嵌套 Maxwell 盒，走完「几何 → 材料 → 求解 → 算力」四步流程。

6.2 过程中的两个工程发现（通用性使用要点）

发现内容
嵌套 Maxwell 盒的界面命名内层盒的外侧相邻区域是外层盒（不是最外层空气）——命名界面必须写 ("box_a_air", "box_all_air")；外层盒用更低 priority 先写、内层后写覆盖、磁体最后覆盖。
HXT 网格不保持镜像对称19,903 个节点中 17,515 个无镜像伙伴——对称性类校验只能到离散误差水平（实测力差 ~7%），要么用结构化网格，要么放宽容差。
通用性结论：换一套几何与材料，四步流程原样复用、物理校验成立——「通用的是管线，不是某一个几何形状」有了实测证据。完整边界清单与三维几何图见专题页 集成通用性.html（或《集成通用性边界.md》）。
