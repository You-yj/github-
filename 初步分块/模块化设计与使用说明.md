# 永磁静磁标势程序模块化设计

## 1. 模块职责

| 模块 | 职责 |
|---|---|
| `magnetostatic.geometry` | 描述空气域、磁体、辅助积分区域和网格尺寸场 |
| `magnetostatic.mesh` | 使用 Gmsh 做共形分割并转换为 FEALPy 四面体网格及区域标签 |
| `magnetostatic.materials` | 描述空气和永磁材料参数 |
| `magnetostatic.pde` | 把命名区域映射到相对磁导率和磁化强度 |
| `magnetostatic.solver` | 建立连续 Lagrange 空间、组装磁标势方程并求解 |
| `magnetostatic.postprocess` | 选择命名区域界面、恢复磁感应强度并积分 Maxwell 应力 |
| `modular_double_magnet_benchmark.py` | 只保存双永磁体算例的具体几何和材料参数 |

原来的 `double_magnet_benchmark.py` 保留不变，用作数值回归基准。

## 2. 数学约定

材料关系采用

$$
\boldsymbol B=\mu_0\left(\mu_r\boldsymbol H+\boldsymbol M\right),
\qquad \boldsymbol H=-\nabla\varphi.
$$

相应弱形式为

$$
\int_\Omega \mu_r\nabla\varphi\cdot\nabla v\,\mathrm dx
=\int_\Omega \boldsymbol M\cdot\nabla v\,\mathrm dx.
$$

当前 benchmark 的所有区域均取 $\mu_r=1$，因此与原程序完全相同。

## 3. 单工况运行

```bash
python modular_double_magnet_benchmark.py --d 0 --p 2
```

一次计算多个位移：

```bash
python modular_double_magnet_benchmark.py --d 0 2 4 10 --p 2
```

每个不同的位移都会改变几何，因此程序会分别重新生成共形网格、建立有限元
空间并求解。Python 调用方式为：

```python
from modular_double_magnet_benchmark import solve_many

results = solve_many([0.0, 2.0, 4.0, 10.0], p=2)
for result in results:
    print(result["d"], result["F0"], result["F1"])
```

## 对比解析解和 ANSYS 数据

打印逐点对比与误差统计：

```bash
python modular_double_magnet_benchmark.py \
    --d 0 2 4 6 8 --p 2 --compare
```

同时输出 CSV 和曲线：

```bash
python modular_double_magnet_benchmark.py \
    --d 0 2 4 6 8 --p 2 --compare \
    --csv results/force_comparison.csv \
    --plot results/force_comparison.png \
    --error-plot results/force_error.png
```

对比对象固定为上磁体受力 `F1`，与 Akoun–Yonnet 解析公式和原 ANSYS
参考表的符号约定一致。ANSYS 表只包含偶数位移 `0, 2, ..., 30 mm`；其他
位移的 ANSYS 数据记为 `NaN`，不会进入误差统计。解析公式可以计算任意位移。

误差统计包括 MAE、RMSE、最大绝对误差及其位移，以及用该分量参考峰值归一化
的 RMSE。逐点参考力接近零时不计算相对误差，以免产生无意义的极大值。

`--plot` 生成磁力—位移对比图；`--error-plot` 生成独立的带符号误差图，
误差定义为 `FEALPy - reference`，单位为 N。误差图中的零水平线用于区分有限元
结果相对参考解是偏大还是偏小。

网格尺寸命令行参数仍以 mm 为单位：

```bash
python modular_double_magnet_benchmark.py \
    --d 4 --p 1 --h-near 1.5 --h-far 6.0
```

模块内部几何和材料数据统一使用 SI 单位。

## 4. 定义其他磁体

增加磁体时，需要完成三件事：

1. 向 `GeometryModel.regions` 添加具有唯一名称的 `BoxRegion`；
2. 在 `ScalarPotentialPDE` 的材料字典中用同一名称绑定 `PermanentMagnet`；
3. 若需要求该磁体的力，增加一个不穿过材料的 Maxwell 空气区域，并为其外表面定义命名界面。

示例材料：

```python
materials = {
    "outer_air": Air(),
    "magnet_a": PermanentMagnet([0.0, 0.0, 3.0e5]),
    "magnet_b": PermanentMagnet([1.0e5, 0.0, 2.8e5]),
}
pde = ScalarPotentialPDE(materials)
```

区域标签的具体整数由网格模块管理。PDE 和后处理只使用区域名称，不依赖
`cell_tag >= 2` 等算例特有约定。

## 5. 当前范围

第一版几何生成器支持任意数量的轴对齐长方体区域。数据接口已经与 Gmsh
状态解耦；后续可增加圆柱、旋转体、STEP 导入等几何类型，而不需要修改 PDE、
有限元求解器或 Maxwell 应力模块。

## 6. 测试与回归

```bash
# 全部测试（16 项：包内单元 11 + 对比模块 4 + 端到端回归 1）
python -m pytest test_magnetostatic.py test_comparison.py test_regression.py
```

- `test_magnetostatic.py`：材料与几何校验、PDE 逐单元系数、变磁导率组装（不依赖 Gmsh）；
- `test_comparison.py`：Akoun–Yonnet 公式与误差统计模块；
- `test_regression.py`：端到端回归——分块程序与最初程序在 p=1、d=0 工况下
  **网格逐位一致**、磁力在求解器噪声水平（约 1e-12 N，PyAMG 的 OpenMP
  归约顺序所致）内一致；磁标势按去均值比较（纯 Neumann 解只确定到常数）。

回归测试依赖 Gmsh 与 PyAMG，单次运行约 15 秒。
