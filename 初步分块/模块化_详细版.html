§1分块动机与架构

1.1 三层结构

算例层modular_double_magnet_benchmark.py —— 只保存本算例的几何尺寸、材料与运行参数（223 行 → 其中几何/材料/流程配置约占一半）
通用模块层magnetostatic/ —— geometry · materials · mesh · pde · solver · postprocess，不依赖任何具体算例
回归基准层double_magnet_benchmark.py（最初程序，位于 最初程序/）—— 保留不变，供端到端数值回归对照

1.2 数据流

GeometryModel + MeshOptions→ GmshTetraMesher→ MeshData→ ScalarPotentialPDE→ ScalarPotentialSolver→ FEMSolution→ MaxwellStressPostprocessor→ 磁力 (3,)

1.3 模块职责

模块职责对应最初程序
geometry空气域、磁体、辅助积分区域与网格尺寸场（不依赖 Gmsh 状态）build_gmsh_mesh 的几何部分

为什么分块：单文件 558 行同时管几何、网格、组装、后处理与对标，改动任何一处都要冒整体回归风险；cell_tag >= 2 这类硬编码把"哪个区域"绑死在算例上。分块后每层只回答自己的问题，且数值路径与最初程序逐句对应（见 §3 回归证据）。

§2模块拆解（左文右码）

2.1 几何描述 magnetostatic/geometry.py

  • BoxRegion：命名轴对齐长方体（center / size / priority），frozen 数据类 + 构造校验（名称非空、尺寸为正）；
  • from_corners：由精确角点构造——消除 center/size 往返的 1 ulp 漂移，使分块版网格与最初程序逐位一致（§3）；
  • lower / upper 属性每次返回新数组，调用方无法原地篡改 frozen 对象；
  • GeometryModel：外层区域 + 嵌入区域 + 命名界面，构造时校验名称唯一、界面引用存在；priority 决定重叠区域归属（磁体覆盖 Maxwell 空气区）。
设计点：几何层只描述数据，不 import Gmsh——网格生成器可以整体替换（圆柱/STEP），几何描述不变。

2.2 材料 magnetostatic/materials.py

  • Air：μr = 1、M = (0,0,0)，磁导率同样校验为正；
  • PermanentMagnet：B = μ₀(μrH + M) 形式，磁化向量校验三维、磁导率为正；
  • 磁化强度以不可变 tuple 存储——frozen 数据类不会被 numpy 数组原地修改（最初程序集成进 fealpy 时沿用同一做法）。

2.3 网格 magnetostatic/mesh.py

  • MeshData：网格 + 逐单元标签 + 名称→整数映射 + 命名界面；tag(name) 是唯一稳定的标签查询入口；
  • _extract_tetra_mesh：Gmsh 非连续编号压缩 + 按体积写单元标签（对应最初程序的 gmsh_to_fealpy_tetra_mesh）；
  • GmshTetraMesher.generate：fragment 共形分割 → 尺寸场 → 线性四面体；空 regions 也有分支（Gmsh 单个体时跳过布尔分割）；标签按 priority 升序写入，高优先级后写覆盖；finally 保证 Gmsh 状态释放。

2.4 PDE 系数 magnetostatic/pde.py

  • validate：每个命名区域都必须有材料，缺材料立即报错——不把未知区域静默当空气；
  • relative_permeability_by_cell / magnetization_by_cell：按 cell_tags == tag 写逐单元系数，形状 (NC,) 与 (NC,1,3)；
  • 不再出现 cell_tag >= 2，也不再固定磁化方向——每个命名区域可绑定独立磁化向量。
\(\displaystyle\int_\Omega \mu_r\nabla\varphi\cdot\nabla v\,\mathrm{d}x=\int_\Omega \mathbf{M}\cdot\nabla v\,\mathrm{d}x\)

2.5 求解器 magnetostatic/solver.py

  • FEMSolution：携带网格、PDE、空间、次数、势与求解状态的完整上下文——后处理无需再传任何参数；
  • assemble：μr 全为 1 走常系数路径，否则给 ScalarDiffusionIntegrator 加逐单元系数（(NC,1) 会被 fealpy 广播到求积点）；
  • solve：PyAMG 平滑聚合预条件 CG；pyamg 缺失回退无预条件 CG 并警告；info < 0 抛错、info > 0 发警告——不再静默返回未收敛结果。

2.6 后处理 magnetostatic/postprocess.py

  • select_interface：按命名界面选面（两侧标签恰为内外区域），不存在则报错；
  • 法向由相邻单元质心方向定向（inside → outside），不再依赖固定 Maxwell 盒中心，可扩展到非凸积分面；
  • compute_force：面两侧 μ₀(M − μr∇φ) 平均得 B，积分 Maxwell 应力——公式与最初程序逐句对应。
\(\mathbf{F}=\int_S \frac{1}{\mu_0}\left[(\mathbf{B}\cdot\mathbf{n})\mathbf{B}-\frac{1}{2}|\mathbf{B}|^2\mathbf{n}\right]\mathrm{d}x\)

2.7 算例入口 modular_double_magnet_benchmark.py

  • make_geometry：四个盒全部用 from_corners 按最初程序的角点算式构造——传入 Gmsh 的浮点逐位一致；
  • make_pde：区域名 → 材料字典，两磁体共用同一 PermanentMagnet（要不同磁化方向就绑定不同实例）；
  • solve：几何 → 网格 → 求解 → 算力四步流水线，返回 {d, solution, phi, F0, F1}；
  • 参考数据（AY 公式、ANSYS 表）与对比统计已拆到 double_magnet_reference.py 与 comparison.py（不依赖 FEALPy 的通用模块）。

2.8 同一工况，两版对比 solve() · before → after

§3数值回归：结构变了，数值没变

3.1 测试清单（16 项全部通过）

3.2 回归判据（为什么不是"逐位一致"）

三条判据：① 网格节点/单元逐位一致（from_corners 消除 1 ulp 几何漂移后成立）；② 磁力 F0/F1 在求解器噪声水平内一致（rtol=1e-9；PyAMG 的 OpenMP 归约顺序带来约 3.4e-12 N 的逐位不确定性，同一程序连跑三次的实测上限）；③ 磁标势按去均值比较（纯 Neumann 解只确定到常数，常数分量随运行漂移）。

3.3 回归测试全文 test_regression.py · 63 行

  • 同一进程内先后运行最初程序与分块程序的 p=1、d=0 工况；
  • 断言网格逐位一致、磁力噪声水平内一致、φ 去均值一致；
  • 单次运行约 15 秒——这就是"分块不改数值"的可复现证据。
# 全部 16 项测试
python -m pytest test_magnetostatic.py test_comparison.py test_regression.py -q
