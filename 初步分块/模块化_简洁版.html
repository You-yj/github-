02为什么分块

单一职责558 行单文件同时管几何、网格、组装、后处理与对标；任何改动都要冒整体回归风险。
名字取代整数cell_tag >= 2 这类硬编码把"哪个区域"绑死在算例上，新算例无法复用。
参考数据独立解析公式与 ANSYS 表从求解代码中抽出，对比与统计成为通用工具。
回归有判据拆分不改数值不是口头保证，而是用端到端测试证明。
为集成铺路清晰的模块边界正是 Stage 03 进 FEALPy 时"谁该去哪一层"的答案草案。
可扩展几何后续加圆柱、旋转体只需换几何/网格模块，PDE 与后处理不动。
分块原则：每层只回答自己的问题——几何描述区域，网格负责 Gmsh，材料与 PDE 提供系数，求解器只管组装与求解，后处理只读解算力。

04相对最初程序的四个关键改进

命名区域取代硬编码cell_tag >= 2 → tag("lower_magnet")；标签整数由网格模块管理，PDE 与后处理只见名字。
拓扑法向定向Maxwell 面法向由相邻单元质心方向决定，不再依赖固定的盒中心，可扩展到非凸积分面。
任意磁化方向每个区域绑定独立 PermanentMagnet，磁化方向不再固定为 +z。
from_corners 逐位几何角点直接构造，消除 center/size 往返的 1 ulp 漂移——那足以让 Gmsh 出拓扑略不同的网格。
求解器防护pyamg 缺失回退无预条件 CG；CG 未收敛发警告——不再静默返回结果。
前置校验缺材料、重名区域、非法尺寸在构造或校验时即报错，不等到求解中途。
不变的部分：数值路径与最初程序逐句对应——积分器配置、PyAMG-CG 参数、应力积分公式全部保持原样。

05同一工况，两版代码

同一段求解逻辑：最初程序把几何、网格、空间、求解、后处理绑在一个类的方法里；分块版只剩「配置与编排」，四步各自调用独立模块。

最初程序 · DoubleMagnetBenchmark.solve()double_magnet_benchmark.py L388–408
    def solve(self, d):
        """为给定位移生成网格和空间，然后完成场求解与磁力计算。"""
        self.d = float(d)
        self.build_gmsh_mesh()

        stiffness, rhs = self.assemble()
        phi = self._solve_linear_system(stiffness, rhs)
        F0 = self.compute_maxwell_force(phi)
        return {"d": self.d, "phi": phi, "F0": F0, "F1": -F0}
分块版 · solve()modular_double_magnet_benchmark.py L106–129
def solve(displacement_mm, p=2, h_near_mm=1.5,
          h_far_mm=6.0, show=False):
    geometry = make_geometry(displacement_mm)
    mesh_data = GmshTetraMesher().generate(
        geometry,
        make_mesh_options(displacement_mm,
                          h_near_mm, h_far_mm, show),
        model_name=f"double_magnet_d{displacement_mm:g}",
    )
    solution = ScalarPotentialSolver(p=p).solve(
        mesh_data, make_pde()
    )
    lower_force = MaxwellStressPostprocessor().compute_force(
        solution, "lower_magnet_maxwell_surface"
    )
    return {"d": displacement_mm, "solution": solution,
            "phi": solution.potential,
            "F0": lower_force, "F1": -lower_force}
